## Calculator Program in C

### 1. Calculator Program Description
This project is a simple, user-friendly calculator developed using C language. It performs basic arithmetic operations and allows users to perform multiple calculations until they choose to exit.

### 2. Concepts Used
- Arithmetic Operators (`+`, `-`, `*`, `/`)
- Conditional Statements (`if-else`)
- `switch-case`
- `do-while` Loop
- Comparison Operators
- Logical Operators (`&&`, `!=`)
- Division by Zero Handling
- `break` and `return`

### 3. Calculator Operations
- Addition
- Subtraction
- Multiplication
- Division
- Exit Option
